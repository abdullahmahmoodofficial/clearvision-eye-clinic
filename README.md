# ClearVision Eye Clinic — 100 Websites Challenge #05

Clear Vision, Expert Care. Multi-page eye clinic website (HTML/CSS/JS) with real photos in `images/`, an interactive 3D eye section, smooth GSAP animations, and a full multi-step online booking system (slots, confirmation reference, WhatsApp).

Part of the **100 Websites Challenge** by Abdullah Mahmood Official — one new business website every day.

## Pages

- `index.html` → Home (hero, 3D eye, services, doctors, gallery, testimonials)
- `about.html` → Our story, values, clinic tour
- `services.html` → Eye tests & surgeries with PKR prices
- `doctors.html` → Specialist profiles with timings
- `gallery.html` → Clinic photo gallery
- `appointment.html` → Multi-step online booking
- `contact.html` → Address, phone/WhatsApp, hours, form

## Tech

Plain HTML, CSS and JavaScript — shared `css/style.css` and `js/` scripts, no build step. Just open `index.html` or serve the folder with any static server.
